# Chintu AI v0.2

Private AI that runs on your own phone or computer. No account, no subscription, no data sent anywhere.

## Put it online (free, 5 minutes)

1. Make a free account at github.com.
2. Tap **+ → New repository**, name it `chintuai`, set it **Public**, create it.
3. Tap **uploading an existing file** and upload all the files in this folder.
4. Go to **Settings → Pages**, under *Branch* choose `main` and **Save**.
5. After about a minute your app is at `https://chintuplay.github.io/chintuai/`.

## Install it like an app

Open that link in Chrome on Android → menu (⋮) → **Add to Home screen / Install app**.
It then opens full screen, works without internet, and shows up in Android's **Share** menu.

## Turn it into an APK (Play Store ready)

Go to pwabuilder.com, paste your link, choose **Android → Generate**. You get an APK/AAB you can install or publish.

## Needs

- Android 12+ with Chrome 121+ (most phones from 2021 on), or Chrome/Edge on a computer.
- Wi-Fi for the first model download (0.5–5 GB). After that it works offline.
